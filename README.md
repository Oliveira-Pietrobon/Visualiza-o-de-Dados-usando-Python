<h2>📊 Atividade de Visualização de Dados</h2>
<p>Projeto desenvolvido em Python utilizando Pandas e Matplotlib para análise e visualização de dados em um Jupyter Notebook.</p>
<p>O objetivo desta atividade é praticar conceitos de:</p>
<ul>
  <li>Manipulação de dados </li>
  <li>Análise exploratória</li>
  <li>Criação de gráficos</li>
  <li>Visualização de informações</li>
  <li>Interpretação de métricas</li>
</ul>
<h2>🚀 Tecnologias Utilizadas</h2>
<ul>
  <li>Python 3</li>
  <li>Pandas</li>
  <li>Matplotlib</li>
  <li>Jupyter Notebook</li>
</ul>

<h2>📈 Funcionalidades</h2>
<p>O notebook realiza:</p>
<ul>
  <li>✅ Leitura de arquivos de dados</li>
  <li>✅ Tratamento e organização das informações</li>
  <li>✅ Análise exploratória dos dados</li>
  <li>✅ Criação de gráficos estatísticos</li>
  <li>✅ Visualização de tendências e métricas</li>
  <li>✅ Geração de insights a partir dos dados</li>
</ul>

<h2>📊 Tipos de Gráficos Utilizados</h2>
<ul>
  <li>Gráfico de barras</li>
  <li>Gráfico de linhas</li>
  <li>Gráfico de pizza</li>
  <li>Histograma</li>
  <li>Dispersão (scatter plot)</li>
</ul>

<h2>▶️ Como Executar o Projeto</h2>
<ol>
  <li>1. Clone o repositório: (https://github.com/Oliveira-Pietrobon/Visualiza-o-de-Dados-usando-Python.git)</li>
  <li>2. Acesse a pasta do projeto:(cd SEU-REPOSITORIO)</li>
  <li>3. Crie um ambiente virtual (Opcional)
Windows(python -m venv venv
venv\Scripts\activate), Linux / Mac(python3 -m venv venv
source venv/bin/activate)</li>
</ol>

<h2>📦 Instale as Dependências</h2>
<p>pip install pandas matplotlib notebook</p>

<h2>▶️ Execute o Notebook</h2>
<p>jupyter notebook</p>
<p>Depois abra: atividade_visualizacao.ipynb</p>
